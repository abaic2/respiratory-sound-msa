# Respira 呼吸音网页 Demo

直接用现代浏览器打开 index.html，无需安装依赖。HTML、CSS、JavaScript 分别位于三个文件中。

支持音频上传与拖放、播放、实际波形和线性 STFT 频谱计算、四种合成音频示例及四分类流程演示。音频在浏览器本地处理。在线字体为可选资源，离线时自动使用系统字体。

**分类不是实际推理**：没有训练权重；合成示例使用对应预设分数，用户上传使用固定混合类示例分数，与上传内容无关。选择模型仅改变展示名称。合成音频不是 ICBHI 患者数据，不保证医学声学真实性。此页面不用于临床判断。

接入真实模型时，需要提供已训练模型及一致的预处理流程，采用后端推理接口或浏览器兼容模型；将 app.js 中分析按钮的预设输出替换为实际输出。当前线性 STFT 图仅用于可视化，不是模型的 Mel 频谱输入。

研究来源：https://github.com/abaic2/respiratory-sound-msa
