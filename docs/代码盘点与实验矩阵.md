## 一、这个目录是什么

**ICASSP 2024 论文 MVST 的官方代码，被改造为毕设的实验矩阵。**

- 论文：He W, Yan Y, Ren J, Bai R, Jiang X. *Multi-View Spectrogram Transformer for
  Respiratory Sound Classification*. ICASSP 2024, pp. 8626–8630.
  DOI: `10.1109/icassp48485.2024.10445825`
- 原仓库：`https://github.com/Huake-EZhou/MVST`（宁波诺丁汉大学）
- 原版思路：梅尔频谱按 **256×1 / 128×2 / 64×4 / 32×8 / 16×16** 五种 patch 形状切分，
  各自过独立 Transformer 编码器，最后门控融合（gated fusion）加权 → 4 类肺音分类。
  论文报告 ICBHI Average Score **66.55%**，Sensitivity 51.10%。
- 上游谱系：整体框架建在 **patch-mix 对比学习**
  （`raymin0223/patch-mix_contrastive_learning`）之上——`method/patchmix.py`、
  `PatchMixLoss`、`--method supcon`、`--ma_update/--ma_beta`、swanlab 都来自那一套。

> **注意**：原版的目录结构是 `16/ 32/ 64/ 128/ 256/` 五个视图目录，本目录里**一个都没有**，
> 说明已被重构。原版卖点的门控融合源码也已不在（`__pycache__` 里残留
> `gated_fusion.cpython-38.pyc`，但 `.py` 已删）。

**本人在其上的改造**（毕设核心贡献）：

1. `Blocks.py` —— 5 个「肺音专用即插即用模块」，均带论文引用：
   BellWeightedAttention、BreathingCyclePerceptionTransformer、
   DiseasePatternDecompositionAttention、FrequencySplitDualPathNetwork、
   VariationalInformationBottleneckEnhancer
2. `models/model_utils.py` 的 **MSA / MSAF** —— 改写自 **AFF/iAFF（Attentional Feature
   Fusion）**，接入了多尺度上下文分支：
   - `context1/2/3` = `AdaptiveAvgPool2d((4,4)/(8,8)/(16,16))`，上采样回原尺寸
   - `MSA`（自调制）：`xo = 2*x*wei`
   - `MSAF` / `Muti_AFF`（双输入融合）：`xo = 2*x*wei + 2*residual*(1-wei)`
3. **两个插入位置**（`baseMSA_start*` vs `baseMSA_end` 的分野）：
   - **Pre-Patch MSA**：在 1×128×1024 原始频谱图上增强，再 patch embedding。
     `PrePatchMSA` 用 32×256 / 64×512 两个尺度，`fusion_weights = nn.Parameter(torch.ones(4))`
     可学习加权求和，支持 `standard/learnable/adaptive` 三种跳跃连接
   - **Post-Patch / 特征级 MSA**：在 AST 输出的 768 维特征上做 `MSA_small_with_skip` + 残差融合

   意味着横向对比 6 个 MSA 变体只能逐个 `diff`。**后续新实验请不要再复制目录**，
   按下面的方式做。

5. **建议的下一步重构**（可选，工作量较大）：
   把 15 个 `main.py`、8 个 `ast.py`、12 个 `icbhi_dataset.py`、15 个 `icbhi_util.py`
   合并成单入口配置驱动，用现有 `run*.txt` 里的原始命令做参数覆盖校验。
   **注意：本机没有 ICBHI 数据集**（在服务器 `/home/yujieyang/bishe/data/ICBHI_final_database`），
   所以这类重构只能做静态验证（语法 + 导入 + 参数映射），无法跑通训练。

### 6.3 后续新实验的正确做法

不要复制目录。把差异收敛成开关：

```python
# 在现有单入口里加参数，而不是复制一份代码
parser.add_argument('--msa_pos', choices=['none', 'pre_patch', 'post_patch'], default='none')
parser.add_argument('--msa_fusion', choices=['sum', 'weighted_sum', 'adaptive', 'gated'], default='sum')
parser.add_argument('--skip_type', choices=['none', 'standard', 'learnable', 'adaptive'], default='none')
parser.add_argument('--skip_ratio', type=float, default=0.3)
```

然后每个实验只对应一行命令（写进 `run_ablations.txt`）：

```bash
python main.py --tag msa_pre_weighted --msa_pos pre_patch --msa_fusion weighted_sum ...
python main.py --tag msa_post_skip      --msa_pos post_patch --skip_type learnable ...
```

这样答辩时是「我设计了 N 组对照实验」，而不是「我复制了 N 份代码」。
